# Study Together — Flutter starter

This is the first Android app UI prototype for **Study Together**.

## Included
- Colorful bilingual-ready home screen (English labels for this first prototype)
- Subject cards: GK & GS, History, Geography, Polity, Economics, General Science
- Current Affairs, MCQ Practice, Mock Test, PDF Notes
- Free and Premium information panels
- Placeholder Register/Login actions and bottom navigation

## Important
This is a UI starter, not a finished production app. Login, cloud database, admin uploads,
payments, tests, and PDF hosting still need secure backend implementation and testing.

## Run on a computer with Flutter installed
1. Install Flutter SDK and Android Studio.
2. Create a Flutter project or extract this folder.
3. Run `flutter pub get`.
4. Run `flutter run`.

A signed Android release (APK/AAB) requires a build environment and app-signing setup.
